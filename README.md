# 詩牌｜Psalm Karuta-Inspired Card Game

A browser-based card game inspired by the traditional Japanese **Karuta** game, adapted into a **Psalm-themed poetry card game**.

Built with **HTML, CSS, and JavaScript**, this project transforms the reading and recognition mechanics of Karuta into an interactive web experience centered on Psalm-based literary content.

## Live Demo

[Play Online](https://celine10811020.github.io/CardGame/)

## About the Project

This project is inspired by the Japanese card game **Karuta**, in which players quickly identify and capture the correct card based on a given reading.

In this adaptation, the traditional format is reinterpreted as a **Psalm poetry card game**.  
Instead of using classical Japanese poems, the content is redesigned around Psalm-related text material, combining literary recognition, memorization, and gameplay interaction in a browser-based format.

## Features

- Karuta-inspired gameplay
- Psalm-themed card content
- Multiple difficulty modes
- Player vs CPU gameplay
- Memorization card position before starting
- Static browser-based deployment with GitHub Pages

## Difficulty Modes

The game includes multiple preset difficulty levels:

- 新手版（Beginner）
- 入門版（Novice）
- 普通版（Normal）
- 困難版（Hard）
- 極難版（Very Hard）
- 專家版（Expert）
- 地獄版（Inferno）

These modes affect game rules such as card count, empty-card settings, and CPU difficulty.
